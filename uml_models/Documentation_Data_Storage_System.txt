The main DataStorage interface writes new patient data to the map it has created. A singleton design pattern is put into place so that only one instance of DataStorage is used. This ensures all records are saved to the same place and will therefore be easy to retrieve. The interface calls DataRetriever when a patient or medical staff wants to access stored values. Through its update() method it calls DataDeletion to remove unwanted records (old, irrelevant...). The DataDeletion class could be made into an interface for various deletion strategies.
